ClassiCube Messenger

ClassiCube Messenger es una aplicación web alojada en Base44 para ser la aplicación "oficial" de ClassiCube para mensajería. Los lenguajes disponibles son:

  • Español
  • Inglés
  • Portugués

Introducción

¿Has estado buscando algún método de comunicación de servidores con el que puedas hablar en ClassiCube?
Un método en dónde hasta un dispositivo de gama baja pueda visitarlo sin ningún tipo de tirones de rendimiento.

ClassiCube Messenger es el lugar perfecto para esto.

Puedes visitar la aplicación con este botón.
