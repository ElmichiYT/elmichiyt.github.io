ElmichiYT Tools

Herramientas que he creado yo o los saqué de otros sitios web.

Memfill

Una herramienta que llena la memoria RAM seleccionada de tu dispositivo.

Se recomienda utilizar esto en dispositivos con 1GB o más de memoria RAM

Hash

Una herramienta para hashear texto y archivos

Metatags

¿Quieres ponerle metadatos a tu sitio web pero no sabes qué poner?
Utiliza esta herramienta fácil.

HTML Editor

Editor de HTML, CSS y JavaScript. Como los cambios no se guardan en la nube ni localmente, ten ciudado al recargar la página porque perderás todo.
Tampoco se recomienda como editor principal, esto está más hecho como editor rápido con vista previa.

Color Selector

Selector de color con el intento de replicar el diseño del Selector de Color de Google.

Base64 File Converter

Herramienta para convertir cualquier archivo a Base64. Útil para poner archivos pequeños como imágenes de baja resolución o íconos directamente en un documento HTML.

Miniaturas YouTube

Una herramienta para extraer todas las resoluciones de una miniatura de YouTube, más 3 frames extra del video especificado. Se puede poner la URL completa o solo poner el ID del video.
